# 密钥安全自查表

**每次提交前必须逐项打钩确认！**

## ☐ .env 文件安全
- [ ] `.env` 文件只存在于我本地电脑
- [ ] `.env` 没有被提交到 GitHub/Gitee
- [ ] 没有在群里发送过完整的 API 密钥

## ☐ 代码中没有密钥痕迹
- [ ] 代码里没有任何形如 `sk-xxxx` 或 `MINIMAX-xxxx` 的字符串
- [ ] 没有把密钥硬编码在 `.py` 文件里
- [ ] 所有密钥都通过 `os.getenv("MINIMAX_API_KEY")` 读取

## ☐ Git 状态干净（5 项全部打钩才算合格）
- [ ] `git status` 输出中不包含 `.env`
- [ ] `.gitignore` 文件中包含 `.env`
- [ ] 代码里没有任何形如 `sk-xxxx` 的字符串
- [ ] `.env` 文件只存在本机，没有发过群
- [ ] 截图/录屏中看不到完整密钥（只显示前 4 位）

## ☐ 截图/录屏安全
- [ ] 截图和录屏中看不到完整的 API 密钥
- [ ] 如果截图了前4位后面的内容已手动打码

## ⚠️ 如果密钥已经泄露
立即执行以下操作：
1. 登录 MiniMax 开放平台控制台
2. 吊销该密钥
3. 重新生成新的 API 密钥
4. 更新本地 `.env` 文件
