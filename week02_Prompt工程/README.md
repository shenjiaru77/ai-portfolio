## 本周做了什么

为汉语国际教育场景写 8 个可复用的 Prompt 模板，并对每个模板做 **R1 → R4 四轮迭代**，
记录「诊断问题 → 改动内容 → 前后对比」，把「会写提示词」变成可复现的方法。

## 迭代方法（每个模板都有的结构）

每个模板固定包含四块：

1. **提示词**：可直接复制的完整 prompt（角色 + 任务 + 约束 + 输出格式）
2. **适用说明**：什么场景用、怎么用
3. **最佳示例**：输入 → 输出范例
4. **迭代实录**：R1 初始 → R2 优化 → R3 定稿 → R4 结构化输出约束，每轮写清「诊断 / 改动 / 对比」

## 本轮最大的收获

**结构化输出约束**：在 prompt 末尾强制规定输出板块（如「阅读短文 / 选择题 A-B-C-D / 答案与解析」），
AI 就不会把内容挤成一段，排版稳定、能直接打印使用。
