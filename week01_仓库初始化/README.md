# 第 1 周 · 仓库初始化与 AI 任务单

> 课程：《人工智能在学习环境中的应用与实践》第 1 周
> 日期：2026-09-21

## 本周做了什么

搭建课程作品集仓库 `ai-portfolio`，并建立用「AI 任务单」记录任务过程的习惯。

## 产出物

| 文件 | 说明 |
|------|------|
| `hello.py` | 第一个 Python 程序（打印问候语），验证运行环境 |
| `ai.任务单.md` | AI 任务单：记录「任务0 仓库初始化」的目标、过程、结果 |

## 学到的关键动作

1. **建仓库**：在 GitHub 上创建 `ai-portfolio`
2. **本地联动**：VS Code 打开仓库文件夹，与远端仓库联通
3. **三件套提交**：`git add` → `git commit` → `git push`
4. **留痕意识**：每个任务用任务单记录「目标 / 过程 / 结果」，方便期末复盘

## 任务单原文

```
任务0 仓库初始化
任务目标：搭建GitHub ai-portfolio仓库，创建3个基础文件
过程：创建仓库，新建README.md、hello.py、ai任务单.md
结果：三个基础文件全部提交至仓库。
```

## 与后续周的关系

仓库就是整个学期的主线：W2 的 8 个 Prompt 模板、W3 的 Python 工具、W4–W6 的 API/本地/双引擎，全部以提交记录作为考核证据。
