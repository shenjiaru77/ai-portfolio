【卡片 1】变量：给数据起名字
────────────────────────
正面：变量 = 值
      words = ["坚持", "商量"]
      level = "4"
背面：变量名是标签，指向内存中的值；同一个变量可以重新赋值。

────────────────────────
【卡片 2】if 条件判断：按条件挑出想要的
────────────────────────
正面：
  if 条件:
      # 做什么
  else:
      # 否则做什么
背面：
  if w["HSK等级"] == "4":
      print(w["词汇"])

────────────────────────
【卡片 3】for 循环：一个个过一遍
────────────────────────
正面：列表推导式
      [结果 for 变量 in 列表 if 条件]
背面：
  # 等价于
  result = []
  for w in words:
      if w["词性"] == "动词":
          result.append(w["词汇"])
  # 列表推导式
  result = [w["词汇"] for w in words if w["词性"] == "动词"]

────────────────────────
【卡片 4】def 函数：打包动作可复用
────────────────────────
正面：
  def 函数名(参数):
      return 结果
背面：
  def filter_by_level(words, level="4"):
      return [w for w in words
              if str(w["HSK等级"]) == str(level)]

【卡片 5】csv.DictReader：CSV 每行是什么？
────────────────────────
正面：每行是一个 dict，键名 = CSV 表头字段名
背面：
  with open("生词表.csv", encoding="utf-8") as f:
      words = list(csv.DictReader(f))
  words[0]["词汇"]   →  第一个词的词汇
  words[0]["词性"]   →  第一个词的词性

────────────────────────
【卡片 6】dict.get(key, 默认值)：词频统计套路
────────────────────────
正面：d.get(k, 0) + 1
背面：
  d = {}
  for w in words:
      d[w["词性"]] = d.get(w["词性"], 0) + 1
  # 运行后 d = {"动词": 3, "名词": 1}

────────────────────────
【卡片 7】encoding="utf-8"：Windows 中文乱码问题
────────────────────────
正面：文件读写必须加 encoding="utf-8"
背面：
  # 错误：Windows 默认 GBK，会乱码
  open("练习.txt", "w")
  # 正确：
  open("练习.txt", "w", encoding="utf-8")

────────────────────────
【卡片 8】sorted(列表, key=函数)：稳定排序
────────────────────────
正面：按指定字段排序，不改变原列表
背面：
  lv4 = sorted(
      [w for w in words if w["HSK等级"] == "4"],
      key=lambda w: w["词汇"]
  )
  # key=lambda w: w["词汇"] 表示按"词汇"字段排序

────────────────────────
【卡片 9】with open(...) as f：自动关文件
────────────────────────
正面：with 语句块结束后自动关闭文件
背面：
  with open("生词表.csv", encoding="utf-8") as f:
      words = list(csv.DictReader(f))
  # 退出 with 块时文件自动关闭，无需 f.close()

【卡片 10】str() 转字符串：类型统一
────────────────────────
正面：为什么要对 HSK等级 加 str() 再比较？
背面：
  # CSV 中数字类型可能是 int 也可能是 str
  str(w["HSK等级"]) == str(level)
  # 两边都转字符串，避免 4 != "4" 的问题
