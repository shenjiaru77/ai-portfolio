# 提示词四件套
## Role角色
你是国际中文教师，熟悉HSK各级别考试标准。
## Task任务
根据提供课文，设计5道阅读理解单选题，包含答案与解析。
## Rules约束
难度锁定HSK4，禁止超纲词汇；解析必须引用原文句子；用Markdown表格输出。
## Few-shot示例
输入：我今天早上吃了包子。
输出：
|题号|题目|A|B|C|答案|解析|
| ---- | ---- | ---- | ---- | ---- | ---- | ---- |
|1|我早上吃了什么？|米饭|包子|面条|B|原文：我今天早上吃了包子|

# 适用说明
适用HSK4课文，用来给留学生出阅读练习题，快速生成标准化考题。
# 最佳示例
【用户输入课文】
我周末去公园散步，看见很多人在放风筝。
【AI输出】
|题号|题目|A|B|C|答案|解析|
| ---- | ---- | ---- | ---- | ---- | ---- | ---- |
|1|我周末去哪里了？|超市|公园|学校|B|原文：我周末去公园散步|
# 迭代实录：HSK阅读出题模板

## R1 第一轮（初始最简提示词）
### 提示词内容
根据课文内容出几道阅读理解选择题。

### 存在问题
1. 没有角色定位，AI输出不稳定
2. 没有题目数量、难度、格式要求
3. 没有答案、没有解析
4. 排版混乱，无法用于教学

### 输出效果
题目数量忽多忽少，难度混乱，无法直接使用。
## R2 第二轮（加入四件套基础规范）
### 优化后的提示词
## Role角色
你是HSK4中文教师。
## Task任务
根据课文出5道阅读单选题。
## Rules约束
词汇难度控制在HSK4，附带答案和简单解析。
## Few‑shot示例
按照常规题目格式输出。

### 优化改进点
1. 增加教师角色
2. 固定出题数量
3. 限制HSK4难度
4. 强制输出答案+解析

### 输出效果
题目规范了，但解析简单、没有固定表格格式、干扰项质量差。
